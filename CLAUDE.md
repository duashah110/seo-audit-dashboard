# Project Instructions

## Project

SEO Audit Dashboard is an AI-assisted web application for analyzing website SEO issues and presenting actionable recommendations.

## Technology Stack

- React
- JavaScript
- Node.js
- Express.js
- HTML
- CSS
- Git and GitHub

## Development Conventions

- Use clear and readable JavaScript.
- Prefer reusable React components.
- Keep components focused on a single responsibility.
- Use meaningful names for variables, functions, and components.
- Avoid unnecessary dependencies.
- Keep user-facing text clear and concise.
- Follow consistent formatting and indentation.
- Do not introduce new libraries without a clear reason.
- Keep frontend and backend responsibilities clearly separated.

## AI-Assisted Development

AI tools may be used for:
- Code generation
- Code review
- Debugging
- Documentation improvements
- Development research

AI-generated code should be reviewed and understood before being included in the project.

## Git Conventions

Use Conventional Commits.

Examples:

- feat: add SEO audit dashboard structure
- docs: improve project documentation
- chore: update project configuration

Keep commits small and focused.
